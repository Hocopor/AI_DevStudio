# AGENTS.md

## Live Plan Rule

- For every substantial task, start by creating a live plan and keep it updated until the work is fully finished.
- The plan must always have exactly one `in_progress` step and all completed work must be reflected in the plan before closing the task.
- For implementation or deployment work, mirror the active plan in `docs/plans/` so the repo keeps an auditable execution trail.
- Do not mark a task finished while the plan still has unresolved steps unless you explicitly document the blocker.
